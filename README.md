# 筑波大学人文社会系 公開講演会

講演ページを Jinsha-Tsukuba/seminars リポジトリに集約します。リポジトリを講演ごとに作成する必要はありません。

## 配置

このZIPを展開し、中身をリポジトリのルートに配置します。`seminars` フォルダーをさらに入れ子にする必要はありません。

- `index.html`：講演一覧
- `2026/1106-mark-turin/index.html`：Turin講演
- `2026/1110-jean-winand/index.html`：Winand講演
- 各講演フォルダー内の `speaker.jpg`、`hero.jpg`、`poster.pdf`：画像・ポスター
- 各講演フォルダー内の `archive-2025.html`：旧講演ページ。旧リポジトリの画像を参照するため、既存のseminar1・seminar2は削除しないでください。

GitHub Pagesをルートから公開した場合のURL：

- https://jinsha-tsukuba.github.io/seminars/
- https://jinsha-tsukuba.github.io/seminars/2026/1106-mark-turin/
- https://jinsha-tsukuba.github.io/seminars/2026/1110-jean-winand/

## 次の講演を追加する方法

1. `年/MMDD-講師名/` フォルダーを追加します。
2. HTMLと関連画像・ポスターを置きます。
3. ルートの `index.html` に講演カードを追加します。
4. 日時・会場・オンライン参加方法・リンクを確認します。

既存リポジトリにREADMEや一覧ページがある場合は、上書きする前に内容を統合してください。現在の接続ではリポジトリが404を返すため、既存内容・既定ブランチ・Pages設定は未確認で、公開は未完了です。
